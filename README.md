# AI Data Engineering Agent

An experimental AI-powered coding agent and workflow assistant optimized for large-scale data engineering, advanced ETL pipelines, and dbt framework optimizations.

## Technical Stack & Architecture
- **Core LLM Platform:** Anthropic Claude 3.5 Sonnet / Opus integrated via **Amazon Bedrock**.
- **Data Infrastructure:** PySpark, dbt, Snowflake, and AWS Cloud services.
- **Agent Framework:** Independent R&D environment utilizing custom tools for automated SQL debugging and data quality compliance.

## Development Goal
We are utilizing the AWS Activate Founders infrastructure credits to scale our testing environment, manage model orchestration on Amazon Bedrock, and run automated deployment validation pipelines.
